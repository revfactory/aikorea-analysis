## 발견 사항 (부적합 상세)

### [치명] 검사항목 24 — 웹 애플리케이션 접근성(이름·역할·값) 부적합
- **근거(라이브):** `main.do` 원본 HTML 전체에서 aria 속성은 `aria-hidden="true"` 1개뿐. 탭 버튼 `<button onclick="committeeActivityTab(event)" class="tabBtn active ...">`는 선택 상태를 CSS class `active`로만 표시하고 `aria-selected`/`role="tab"`이 없음. 커스텀 드롭다운(nice-select), fullPage.js 섹션 네비, 통합검색 위젯도 동일.
- **법적 위험:** 스크린리더 사용자가 "어느 탭이 선택됐는지", "드롭다운이 열렸는지"를 알 수 없어 핵심 탐색·필터 기능을 사용 불가 → 장애인차별금지법상 정당한 편의 미제공(차별 소지).
- **권고:** 탭에 `role="tab"`/`role="tablist"`/`aria-selected` 적용, 토글 버튼에 `aria-expanded`, 커스텀 select를 네이티브 `<select>` 기반 또는 ARIA combobox 패턴으로, 검색에 `<label>`/`aria-label` 부여.
  ```html
  <div role="tablist" aria-label="위원회 활동">
    <button role="tab" id="tab1" aria-selected="true" aria-controls="panel1">전체회의</button>
  </div>
  ```

### [치명] 검사항목 1 — 적절한 대체 텍스트 부적합
- **근거(라이브):** 위원회 소개 4대 원칙 이미지(`bg-img-01.png`~`bg-img-04.png`)에 **alt 속성 자체가 없음**(`content.do?menu_cd=000005`). 메인 캐러셀 이미지는 템플릿 `alt="이미지"`로 렌더(비서술). 조직도 이미지 alt가 로고 텍스트 재사용(조직 구조 미설명). 갤러리(`garList`) 썸네일은 background-image라 대체수단 없음. **MI 소개(`content.do?menu_cd=000031`) 일부 디자인 이미지가 빈 alt(`[EMPTY]`)** — 의미 전달용이면 부적합, 장식이면 적합이므로 이미지별 의도 확인 필요(출처: content-policy-analyst 공유 `02_content_policy.md`, `pages/05_mi-intro.md` 22·51행).
- **법적 위험:** 시각장애 사용자가 핵심 시각 정보를 인식 불가. 단, 4대 원칙·조직 위계·갤러리 제목은 **본문/카드 텍스트로도 제공**되어 정보 손실은 부분 완화(아래 권고로 마크업만 정정하면 됨).
- **권고:** 장식 배경(`bg-img-*`)이면 `alt=""` 명시(스크린리더가 파일명 읽기 방지). 캐러셀은 게시물 제목을 alt에 동적 주입(`alt="${item.title}"`). 조직도가 정보전달이면 조직 구조를 설명하는 alt 또는 인접 텍스트 연결. 갤러리 썸네일은 `<img alt="게시물 제목">`로 전환 권장.

### [주요] 검사항목 17 — 기본 언어 표시 부적합 (영문판)

- **법적 위험:** 스크린리더가 영문을 한국어 음성엔진으로 읽어 영어권·청각 보조 사용자가 내용 파악 불가. 영문판 전 페이지 결함.
- **권고:** 영문 템플릿 `<html lang="en">`로 수정. 미번역 UI 텍스트("본문 바로가기","Top으로 이동")도 영문화.
