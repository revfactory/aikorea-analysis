## 방문 페이지 응답 코드 (정상)

정찰에서 방문한 한글판 17개 페이지 + 영문판 메인/정책 + 상세 샘플 1건은 **전부 HTTP 200**으로 정상 응답. 4xx/5xx 없음.

- 단, "정상 200"이 곧 콘텐츠 존재를 의미하지 않음(아래 soft-404 참조).
