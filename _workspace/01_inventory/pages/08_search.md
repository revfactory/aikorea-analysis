## HTML 구조 / 폼 접근성

- `<title>`: 국가인공지능전략위원회
- 본문 텍스트(렌더 후): "전체 컨텐츠 검색 / 게시물 검색 / 콘텐츠 검색 총 N건 / 게시물 검색 총 N건"
- `<form>` 요소: **0개** — 검색은 JS 기반 입력+버튼 처리(엔터/클릭으로 동작 추정).
- 검색 입력 필드(input[type=text]) 4개 관찰:
  | # | placeholder | aria-label | label 연결 |
  |---|-------------|-----------|-----------|
  | 1 | 검색어를 입력해주세요. | (없음) | 있음 |
  | 2 | 검색어를 입력해주세요. | (없음) | **없음** |
  | 3 | 검색어를 입력해주세요. | (없음) | 있음 |
  | 4 | 검색어 입력 | (없음) | **없음** (헤더 검색창 추정) |
  - `name` 속성 비어 있음. 일부 필드는 label 미연결, placeholder에만 의존.
